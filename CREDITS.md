# Credits

Luv in Space uses the following third-party data. Each asset's `SOURCE.md` under `assets/` gives its source URL, date, licence and how it was made (`decision 13: Asset storage and attribution`).

- Earth's surface: NASA Earth Observatory (Blue Marble Next Generation); `assets/earth/blue-marble-5400.jpg`, see `assets/earth/SOURCE.md`. NASA does not endorse this game.
- Earth's night lights: NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Román, NASA GSFC (Black Marble 2016); derived `assets/earth/black-marble-5400.jpg`, see `assets/earth/SOURCE.md`.
- Earth's clouds: NASA Goddard Space Flight Center Image by Reto Stöckli (Blue Marble clouds); derived `assets/earth/clouds-5400.jpg`, see `assets/earth/SOURCE.md`.
- Stars: HYG database by David Nash (astronexus), https://codeberg.org/astronexus/hyg, under CC BY-SA 4.0; the derived table `assets/stars/hyg-6.5.sexp` is under the same licence (`assets/stars/LICENSE`), see `assets/stars/SOURCE.md`.
- Fonts: Monaspace Neon by GitHub Next (https://github.com/githubnext/monaspace) and Iosevka Aile by Renzhi Li (https://github.com/be5invis/Iosevka), both under the SIL Open Font License 1.1, copied from luv's `fonts/`; `assets/fonts/`, see `assets/fonts/SOURCE.md` and the licence files beside the fonts.
- Engine: luv by Mikael Brockman, https://github.com/mbrock/luv.
